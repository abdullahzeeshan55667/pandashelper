# Python Teaching Docs

This repository keeps Python explanations concise and example-driven so beginners can move quickly from reading to practice. Each lesson focuses on:

- What the concept is and why it matters.
- A minimal code example.
- A short checklist for self-assessment.

The `session/` folder contains a prompt, an interactive shell, and scripts you can use to run an LLM-led teaching session. Progress is stored locally so the learner can resume later.
